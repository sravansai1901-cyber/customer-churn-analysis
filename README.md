# Customer Churn Analysis

## Project Overview
This project predicts customer churn using Machine Learning and Flask Web Application.

The system analyzes customer data and predicts whether customers may leave the business.

---

## Features

- Customer churn prediction
- CSV file upload
- Bulk customer analysis
- Pie chart visualization
- Modern dashboard UI
- Machine learning integration

---

## Technologies Used

- Python
- Flask
- Machine Learning
- Scikit-learn
- Pandas
- Matplotlib
- HTML
- CSS

---

## Machine Learning Algorithm

- Decision Tree Classifier

---

## How to Run the Project

1. Install required libraries

```bash
pip install flask pandas scikit-learn matplotlib
```
